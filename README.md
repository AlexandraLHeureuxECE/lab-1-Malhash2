# React Tic-Tac-Toe with Time Travel

A fully interactive, web-based Tic-Tac-Toe game built with React. This application features visual theme customization (Light, Dark, Neon, Retro), interchangeable marks (Emojis, Classic, etc.), and a "Time Travel" history feature that allows players to revisit and change past moves.

## 🔗 Live Demo
**Play the game here:** [https://AlexandraLHeureuxECE.github.io/lab-1-Malhash2](https://AlexandraLHeureuxECE.github.io/lab-1-Malhash2)

## 🤖 LLM Tools Used
* **Model:** Gemini 3 Pro
* **Role:** Code generation, debugging, logic implementation, and CSS styling.

## ✨ Features
* **Single-device Multiplayer:** Classic 2-player mode.
* **Time Travel:** View move history and jump back to any previous turn to correct mistakes or explore alternate outcomes.
* **Theming:** Instant toggle between 4 distinct visual themes (Light, Dark, Cyberpunk Neon, Retro Gameboy).
* **Custom Marks:** Switch player icons between Standard (X/O), Emojis, Pets, Space, and Math symbols.
* **Responsive Design:** Works on desktop and mobile.

## 🛠️ Running Locally

Follow these instructions to run the project on your local machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1.  **Clone the repository** (or download the source code):
    ```bash
    git clone [https://github.com/AlexandraLHeureuxECE/lab-1-Malhash2.git](https://github.com/AlexandraLHeureuxECE/lab-1-Malhash2.git)
    cd tic-tac-toe
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm start
    ```

4.  **Open in Browser:**
    The app should open automatically at `http://localhost:3000`.
